# Changelog

All notable changes to this skill are documented here.

## [1.7.0] - 2026-11-23

### Changed

- Rebuilt as a complete claim guide with no calculator. The Tax Authority simulator is the only source of an amount.
- Added track questions, filing windows with source dates, the red-track check, base-period concepts, documents, appeal routes and already-filed steps.
- Removed the suggestion to extend a leave that has already ended, and the calculator script.

## [1.6.1] - 2026-11-23

- Safety release: removed the calculation after versions 1.4.0 to 1.6.0 usually showed twice the correct amount.
