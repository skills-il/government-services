# אוטומציית טפסים ממשלתיים ישראליים

## הבהרה משפטית

כלי זה הוא כלי מידע חינמי, הפועל באמצעות מודל בינה מלאכותית. הוא מסייע לכם לארגן ולמלא טפסים מול רשויות. כל תוצריו מופקים באופן אוטומטי על ידי מודל בינה מלאכותית, ללא מעורבות, בדיקה או אישור של עורך דין, יועץ מס או רואה חשבון. הפלט אינו ייעוץ משפטי, מיסויי או מקצועי אחר. מודל בינה מלאכותית עלול לשגות, להשמיט נתונים או להציג מסקנה שגויה.

טופס המוגש לרשות הוא מסמך שאתם אחראים לתוכנו, ופרטים שגויים בו עלולים לגרור אחריות. בדקו כל שדה לפני הגשה, ואל תגישו טופס שאינכם מבינים את תוכנו. הכלי אינו מהווה תחליף לייעוץ המתחשב בנתונים ובצרכים המיוחדים של כל אדם, וכל שימוש בפלט ובתוצריו הוא באחריותו הבלעדית של המשתמש.

### שלב 2: כללי יסוד לסוכן בפורטל ממשלתי

אלה כללים מחייבים, לא המלצות:

1. **שירותים מזוהים הם אישיים.** תנאי השימוש של gov.il קובעים שהשימוש במערכת ההזדהות לצורך שירותים מזוהים הוא אישי, ושימוש של אדם אחר בשם המשתמש מפר את התנאים ועשוי להיחשב בנסיבות מסוימות כעבירה פלילית. החריג היחיד הוא בן משפחה (בן או בת זוג, הורה, ילד, אח או אחות) שפועל בהסכמת המשתמש. סוכן שמגיש עבור צד שלישי שאינו בן משפחה (מעסיק עבור עובד, רואה חשבון עבור לקוח) עוצר ומפנה לערוץ המייצגים של אותו גורם.
2. **אף פעם לא לקבל, לשמור או להקליד את הסיסמה או הקוד החד-פעמי של המשתמש.** פותחים דפדפן גלוי (`headless=False`) ונותנים למשתמש להתחבר בעצמו. תנאי השימוש מחייבים את המשתמש לשמור את הסיסמה בסוד ולא למסור אותה לאחר.
3. **אף פעם לא לשלוח, לחתום או לשלם בלי אישור מפורש להגשה הזו**, שניתן אחרי שהמשתמש ראה את הטופס המלא (צילום מסך או חלון הדפדפן הפתוח).
4. **אף פעם לא לסמן תיבת הצהרה** ("אני מצהיר שהפרטים נכונים") במקום המשתמש, ואף פעם לא להמציא ערך שהמשתמש לא מסר. משאירים את השדה ריק ושואלים.
5. **אף פעם לא לפתור CAPTCHA או להעביר אותו לשירות פתרון.** עוצרים ומעבירים את השליטה למשתמש.
6. **לא שומרים מידע אישי אחרי סיום העבודה.** מוחקים דפים שנשמרו, קבצי PDF ממולאים וצילומי מסך עם מספרי זהות, פרטי בנק או מסמכים רפואיים, אחרי שהמשתמש שמר את מה שהוא צריך.

### שלב 3: אימות שדות ישראליים

לפני שממלאים טופס, תעשו אימות לכל הנתונים בפורמט ישראלי:

**אימות תעודת זהות:**
מספר תעודת זהות ישראלי הוא 9 ספרות עם ספרת ביקורת (וריאנט של Luhn):
```python
import re

def validate_tz(id_number: str) -> bool:
    """אימות מספר תעודת זהות ישראלית."""
    id_str = id_number.strip().zfill(9)
    # ASCII digits only: str.isdigit() also accepts full-width digits
    if not re.fullmatch(r"[0-9]{9}", id_str):
        return False
    if id_str == "000000000":
        return False  # עובר Luhn אבל הוא placeholder, לא ת״ז אמיתית
    total = 0
    for i, digit in enumerate(id_str):
        val = int(digit) * (1 + (i % 2))
        if val > 9:
            val -= 9
        total += val
    return total % 10 == 0
```

**פורמטים של מספרי טלפון ישראליים** (לפי תוכנית המספור של משרד התקשורת):

| סוג | תבנית | הערות |
|-----|-------|-------|
| נייד | 05X-XXXXXXX (10 ספרות) | המאמת הנלווה בודק את מבנה הקידומת 05X, לא את המפעיל ולא אם הקידומת מוקצית; ניוד מספרים אומר שקידומת לעולם לא מזהה את המפעיל הנוכחי |
| קווי גיאוגרפי | 0A-NXX-XXXX (9 ספרות) | הספרה A היא 2 (ירושלים), 3 (תל אביב), 4 (חיפה והצפון), 8 (השפלה והדרום), 9 (השרון); הספרה הראשונה של המספר המקומי N היא 2-9 |
| ארצי (07X) | 07P-NXX-XXXX (10 ספרות) | הספרה P היא 2-9 (072 עד 079); נפוץ בקווי VoIP וכבלים. מאמת שבודק 9 ספרות דוחה אותם בטעות |
| בינלאומי | +972-5X-XXXXXXX | תסירו 0 מוביל, תוסיפו +972 |

**פורמט כתובת ישראלית:**
```
{שם רחוב} {מספר בית}, {דירה} (אופציונלי)
{שם עיר}, {מיקוד (7 ספרות)}
```

לאיתור מיקוד השתמשו בשירות של דואר ישראל: `https://mypost.israelpost.co.il/zipcodesearch`. הדף חסום לבוטים ולא ניתן היה לקרוא אותו אוטומטית ב-3.11.2026, לכן פותחים אותו בדפדפן של המשתמש עצמו; אם הוא לא נטען, משתמשים באיתור המיקוד באתר israelpost.co.il. הרבה שירותים מזוהים מושכים את הכתובת ממרשם האוכלוסין, לכן בדקו מה הפורטל כבר מציג לפני שמקלידים כתובת חדשה.

**שדות בעברית בלבד מול שדות שמתירים אנגלית:** רוב הטפסים הממשלתיים דורשים טקסט בעברית. חריגים:

| הקשר | קלט מותר |
|------|----------|
| טפסי דרכון / אזרחים זרים (שמות) | אנגלית (לפי הדרכון) |
| הצעות שם חברה ברשם החברות | עברית עיקרית, תעתיק לועזי אופציונלי |
| IBAN / הפניות לחשבון בנק | תווים לטיניים (IL + ספרות) |
| דוא"ל וכתובות URL | לטיני |

בכל ספק, התאימו לכתיב ולכתב של המסמך הרשמי של המשתמש (תעודת זהות, דרכון, תעודת התאגדות).

### שלב 4: הגדרת אוטומציית דפדפן (טפסים אונליין)

התקנה והגדרה של Playwright לפורטלים ממשלתיים בעברית (RTL):

```bash
pip install playwright
playwright install chromium
```

**דפוסים מרכזיים לפורטלי gov.il:**
```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)  # המשתמש מתחבר כאן, לא הסוכן
    context = browser.new_context(locale="he-IL")
    page = context.new_page()
    page.goto("https://my.gov.il")

    # ממתינים עד שהמשתמש התחבר בעצמו (שלב 2, כלל 2).
    input("Log in in the browser window, then press Enter here...")

    # חשוב: סלקטורים לא יציבים בין פורטלי gov.il.
    # אל תניחו [data-testid="form-container"]. תמיד תספרו את ה-DOM
    # (page.content() או DevTools) ותגלו את הסלקטור הספציפי לפורטל
    # לפני שמסתמכים עליו.
    page.wait_for_selector("form, [role='main']", timeout=15000)

    # מילוי שדות טקסט RTL
    page.fill('input[name="firstName"]', "ישראל")
    page.fill('input[name="lastName"]', "ישראלי")
    page.fill('input[name="idNumber"]', "123456782")

    # תאריכים בפורמט ישראלי DD/MM/YYYY
    page.fill('input[name="birthDate"]', "15/03/1990")

    # רשימות נפתחות עם אפשרויות בעברית
    page.select_option('select[name="city"]', label="תל אביב-יפו")
```

### שלב 5: מילוי טפסי PDF (טפסים להורדה)

לטפסי PDF ממשלתיים עם שדות למילוי, השתמשו ב-pypdf (היורש המתוחזק של PyPDF2 שיצא משימוש):

```python
from pypdf import PdfReader, PdfWriter

reader = PdfReader("tofes_101.pdf")
fields = reader.get_fields()  # חובה: לספור שדות לפני שמנחשים שמות
print(list(fields))

writer = PdfWriter()
writer.append(reader)
writer.update_page_form_field_values(
    writer.pages[0],
    {"shem_prati": "ישראל", "shem_mishpacha": "ישראלי"}
)
writer.write("tofes_101_filled.pdf")  # בלי השורה הזו שום דבר לא נשמר
```

תמיד הריצו `reader.get_fields()` ראשון. שמות שדות משתנים בין גרסאות טופס ובין משרדים, אסור להניח שם משימוש קודם. אפשר לבדוק את אותו AcroForm ברמה נמוכה יותר עם pikepdf (`pdf.Root.AcroForm`), אבל pypdf הוא המסלול שנבדק כאן.

**ערכים בעברית ומראה השדה:** ב-pypdf 6.x, מילוי שדה שהגופן שלו לא כולל אותיות עבריות מדפיס את האזהרה "contains characters not supported by font encoding". הערך עצמו נשמר נכון, והקובץ מסומן כך שהמציג יצייר את השדה מחדש, אבל המראה שצויר מראש עלול להציג ג'יבריש. פתחו את הקובץ הממולא במציג PDF אמיתי ובדקו בעיניים כל שדה בעברית לפני שהמשתמש מעלה אותו, ואל תשטחו (flatten) את הטופס.

### שלב 6: טיפול בדפוסי טפסים ממשלתיים נפוצים

**טופס 101 (כרטיס עובד):**
העובד ממלא וחותם עליו ומוסר אותו, עם המסמכים הנלווים, למעסיק או למשלם הקצבה: בתוך 7 ימים מתחילת העבודה או מקבלת המשכורת הראשונה (המוקדם מביניהם), בתחילת כל שנת מס (1 בינואר), ובתוך 7 ימים מכל שינוי בפרטים. גמלאים שמלאו להם 70 ומקבלי קצבאות שונות עשויים להיות פטורים מהגשה מחודשת כל שנה אם לא חל שינוי בהכנסות; בדקו את תנאי רשות המסים לפני שמבקשים מהם להגיש שוב. הטבה בגין תואר אקדמי או תעודת מקצוע (טופס 119) מצורפת לטופס 101 הזה. העובד מצהיר על עובדות (ילדים, מקום מגורים, לימודים, הכנסה נוספת), ומערכת השכר של המעסיק מתרגמת אותן לנקודות זיכוי, לכן לא מקלידים מספר נקודות זיכוי לטופס 101.
טופס 101 אלקטרוני הוא אפשרות, לא חובה: כללי רשות המסים מאפשרים למעסיק להפיק את הטופס אלקטרונית, כתחליף למילוי ידני, דרך מערכת מאושרת. הדף `https://www.gov.il/he/service/itc-application-for-electronic-101` מיועד לבתי תוכנה ולמעסיקים שמבקשים אישור למערכת כזו, ואינו מסלול הגשה לעובדים.

**דוח שנתי (1301 או 135):**
דף הדוח השנתי לשנת 2025 ב-gov.il מציע הגשה מקוונת מלאה משנת 2019 ואילך, ומאפשר הגשה ידנית (בנייר) למי שמעל גיל פרישה, למי שהכנסתו נמוכה, ולמי שאינו חייב בהגשת דוח ומבקש החזר מס.

מועדי ההגשה לשנת המס 2025: מי שחייב בדוח שאינו מקוון עד 29.5.2026, מי שחייב בדוח מקוון עד 30.6.2026. המועדים האלה עברו; מי שחייב ולא הגיש מגיש עכשיו, והסוכן בודק מחדש בדף של gov.il את המועדים לשנת המס הבאה. מי שפטור מהגשה מקוונת יכול להגיש את טפסי ה-PDF שבדף דרך מערכת פניות הציבור.

1. התחברות לאזור האישי ברשות המסים (המשתמש מתחבר בעצמו, ראו שלב 2)
2. נתונים נדרשים: מקורות הכנסה, ניכויים, זיכויים
3. מחזיקים בהישג יד את 106, 857 ו-867; הנתונים שלהם מוקלדים לשדות הדוח, ומעלים קבצים כשהמערכת מבקשת
4. פורמט תאריך: תמיד DD/MM/YYYY

**תביעות ביטוח לאומי:**
1. **קודם בודקים אם צריך להגיש תביעה בכלל.** למעט במקרה של לידת בית, דמי לידה משולמים אוטומטית, בלי תביעה, לעובדת עצמאית, לשכירה שלמעסיק שלה יש הסדר עם ביטוח לאומי והוא מגיש עבורה, למי שקיבלה גמלה לשמירת היריון עד הלידה, ולמי שקיבלה דמי אבטלה עד חודש לפני הלידה. לידת בית מחייבת תמיד הגשת תביעה. את התביעה מגישים לא יאוחר מ-12 חודשים מיום הזכאות הראשון, ואת הטופס המקוון אפשר למלא רק אחרי הלידה. כל מעסיק מאשר בגוף הטופס את חודשי העבודה ואת השכר ב-10 החודשים שקדמו להפסקת העבודה (טופס מכל מעסיק).
2. התחברות לשירות האישי של ביטוח לאומי (ps.btl.gov.il); זו מערכת ההזדהות של ביטוח לאומי, לא ההזדהות הלאומית
3. מזהים את סוג התביעה ואת המסמכים שהיא דורשת, מתוך טופס התביעה עצמו
4. מעקב אחרי התביעה באזור האישי

**הגשות לרשם החברות:**
1. רישום חברה מקוון ("רישום חברה בקליק") מתבצע בתאגידים ברשת, בכניסה דרך ההזדהות הלאומית; התקנון והצהרות בעלי המניות והדירקטורים מאושרים אחר כך באופן מקוון על ידי כל צד, בלי סריקות מאומתות על ידי עורך דין
2. מכינים יותר מהצעת שם אחת בעברית: מדריך הרישום המקוון של הרשם משנת 2017 (מסלול הכרטיס החכם) חייב שלוש הצעות לפי סדר עדיפות, והמדריך העדכני של רישום חברה בקליק לא מציין מספר, לכן פועלים לפי מה שהטופס מבקש
3. אגרות (טבלת רשות התאגידים לשנת 2026): רישום מקוון 2,559 ש"ח (אגרה מופחתת), רישום רגיל 3,123 ש"ח; בנוסף יש אגרה שנתית בכל שנה אחרי הרישום, וחשוב להגיד את זה לבעלים
4. לגבי דוח שנתי ושינויים בדירקטורים או בבעלי מניות, בודקים בדף השירות של רשות התאגידים מהו מסלול ההגשה העדכני

### שלב 7: סיבות דחייה נפוצות

תבדקו את הטופס המלא מול הבעיות האלה לפני הגשה:

### שלב 8: הזדהות וחתימות

התחברות וחתימה הן שני דברים שונים.

**התחברות (הזדהות):**
- **הזדהות לאומית (gov.il, my.gov.il, רישום חברה מקוון בתאגידים ברשת):** מספר תעודת זהות, הסיסמה שנבחרה, וקוד אימות שנשלח בכל פעם במסרון או בהקראה קולית. ממאי 2025 אפשר גם להתחבר בטלפון הנייד עם האמצעים הביומטריים של הטלפון, בלי סיסמה ובלי קוד (passkey). תעודת זהות ביומטרית היא אחת הדרכים להירשם, בעמדה עם קורא כרטיסים.
- **האזור האישי ברשות המסים:** מערכת הזדהות עצמאית (ראו שלב 1).
- **ביטוח לאומי:** מערכת עצמאית; משתמש רשום מתחבר עם מספר תעודת זהות וקוד סודי שנשלח לנייד הרשום.

**חתימה:** טפסי gov.il שמקבלים חתימה אלקטרונית מבוססת תעודה עובדים עם כרטיס חכם או Token שמחזיק תעודה של גורם מאשר מוסמך (בישראל: קומסיין ופרסונל איי.די.), יחד עם קורא כרטיסים ותוכנת חתימה. רישום חברה מקוון שונה: מגיש הבקשה נכנס בהזדהות לאומית, וכל בעל מניות ודירקטור מאשר (חותם) אחר כך באופן מקוון מקישור שנשלח לדוא"ל שלו; בדקו במסך האישור איך הם מזדהים. כשטופס דורש חתימה, הסוכן לא יכול לספק אותה: המשתמש מבצע כל שלב חתימה בעצמו.

### שלב 9: שליחה ואימות

אחרי מילוי הטופס:
1. **צילום מסך לפני שליחה**, וקבלת אישור מפורש מהמשתמש (שלב 2, כלל 3)
2. **בדיקת כל שדות החובה**, טפסים ממשלתיים דוחים הגשות חלקיות
3. **שמירת מספר האישור** שמוצג אחרי השליחה
4. **הורדת PDF קבלה** כשזמין
5. **רישום איפה עוקבים אחרי הסטטוס**: האזור האישי באותו פורטל

### שלב 10: התאוששות משגיאות

- **האוטומציה לא עובדת, או שאין למשתמש פרטי כניסה**: חוזרים למסלולים האנושיים, כמו מערכת פניות הציבור לדוח מס בנייר, או מרכז השירות של הגוף
- **פקיעת חיבור**: הפורטלים מנתקים אחרי חוסר פעילות, והמגבלה שונה מפורטל לפורטל. שומרים התקדמות כשהפורטל מאפשר ומחזירים את ההתחברות למשתמש
- **CAPTCHA**: עוצרים ומעבירים את השליטה למשתמש (שלב 2, כלל 5)
- **מסך הכניסה השתנה**: מערכות ההזדהות משתנות במהלך 2026; סורקים את הדף מחדש במקום להריץ סקריפט ישן
- **עומס**: אתר רשות המסים איטי יותר סביב מועדי הגשת הדוחות השנתיים

## דוגמאות

### דוגמה 1: מילוי טופס 101 בעבודה חדשה
המשתמש אומר: "התחלתי עבודה חדשה ומשאבי אנוש ביקשו ממני טופס 101"
פעולות:
1. מוודאים שהמשתמש הוא העובד (הטופס שלו למילוי) ולאיזו שנת מס
2. שואלים אם המעסיק עובד עם מערכת טופס 101 אלקטרוני; אם כן, המשתמש ממלא שם. אחרת מורידים את טופס 101 של השנה הנוכחית מדף הטפסים של רשות המסים
3. מאמתים את תעודת הזהות, ואז ממלאים פרטים אישיים והצהרות עובדתיות (ילדים, מגורים, לימודים, מעסיק נוסף), בלי מספר נקודות זיכוי
4. שומרים את ה-PDF הממולא, המשתמש בודק בעיניים כל שדה בעברית, חותם ומוסר למעסיק בתוך 7 ימים, עם צילום תעודת זהות וספח
תוצאה: טופס 101 ממולא שמחכה לחתימת המשתמש, והערה שמעסיק נוסף עשוי לחייב תיאום מס (הפניה ל-`israeli-tax-coordination`)

### דוגמה 2: דמי לידה בביטוח לאומי
המשתמשת אומרת: "תעזרו לי להגיש תביעת דמי לידה בביטוח לאומי"
פעולות:
1. שואלים אם הלידה הייתה בבית (אז תמיד צריך תביעה), ואחרת אם היא עצמאית, אם המעסיק שלה מגיש עבורה, אם קיבלה גמלה לשמירת היריון עד הלידה, או דמי אבטלה עד חודש לפני הלידה; אם אחד מאלה נכון, התשלום אוטומטי ואין מה להגיש
2. אחרת, אחרי הלידה, המשתמשת מתחברת בעצמה ל-ps.btl.gov.il
3. ממלאים את טופס התביעה עם הפרטים שלה; כל מעסיק מאשר את החלק שלו (חודשי עבודה ושכר ב-10 החודשים שלפני הפסקת העבודה); מאמתים IBAN של החשבון שהטופס מבקש; מגישים בתוך 12 חודשים מיום הזכאות
4. מעלים רק את המסמכים שהטופס מבקש, מצלמים מסך ומקבלים את אישורה לפני השליחה
תוצאה: או "אין צורך בתביעה, התשלום אוטומטי", או תביעה שהוגשה עם מספר אישור

### דוגמה 3: רישום חברה חדשה באופן מקוון
המשתמש אומר: "אני רוצה לרשום חברה בע"מ חדשה"
פעולות:
1. המשתמש נכנס לתאגידים ברשת (https://ica.justice.gov.il/IcaSite) דרך ההזדהות הלאומית
2. מכינים הצעות שם בעברית לפי סדר עדיפות (ראו שלב 6)
3. מזינים פרטי מייסדים, דירקטורים ומניות; כל בעל מניות ודירקטור מאשר אחר כך באופן מקוון מהקישור שנשלח לדוא"ל שלו
4. מציינים את אגרת הרישום המקוון לשנת 2026 (2,559 ש"ח) ואת האגרה השנתית החוזרת
תוצאה: בקשת רישום שהוגשה ומחכה לאישור המקוון של כל הצדדים

### דוגמה 4: עדכון כתובת במשרד הפנים
המשתמש אומר: "עברתי דירה ואני צריך לעדכן כתובת"
פעולות:
1. המשתמש פותח את שירות שינוי הכתובת ב-gov.il ומתחבר בהזדהות לאומית
2. אימות פורמט הכתובת החדשה (רחוב, עיר, מיקוד דרך דואר ישראל)
3. מילוי טופס שינוי הכתובת; צילום מסך ואישור מהמשתמש
4. שליחה ושמירת האישור; תזכורת שגופים אחרים (למשל העירייה) עשויים לדרוש עדכון נפרד
תוצאה: בקשת שינוי כתובת הוגשה עם מספר אישור

- סלקטורים בפורטלי gov.il לא יציבים בין שירותים. אסור לעשות שימוש חוזר בסלקטור מפורטל אחר, תמיד לספור את ה-DOM קודם.

## פתרון בעיות

### שגיאה: "פקיעת סשן" ב-gov.il
סיבה: חיבורים לפורטלים ממשלתיים פגים אחרי חוסר פעילות (אין מגבלה מפורסמת, והיא שונה מפורטל לפורטל)
פתרון: מחזירים את ההתחברות למשתמש וממשיכים מהשלב האחרון שנשמר.

### שגיאה: "תעודת זהות לא תקינה"
סיבה: מספר הזהות נכשל באימות ספרת ביקורת, או שזה placeholder כמו `000000000`

### שגיאה: "טקסט עברי מוצג שגוי ב-PDF"
סיבה: לגופן של השדה אין אותיות עבריות, ולכן המראה ש-pypdf מצייר שגוי אף שהערך השמור נכון (נבדק עם pypdf 6.12 על טופס בדיקה)
פתרון: פותחים את הקובץ במציג PDF, שמצייר את השדות מחדש מהערך השמור; בודקים בעיניים; לא משטחים. עדיף הטופס הרשמי, שהשדות שלו בדרך כלל כוללים גופן עברי.

### שגיאה: "שדה טופס לא נמצא"

פתרון: תציגו קודם את כל השדות עם `reader.get_fields()`, ואז תתאימו לפי בדיקת תוויות השדות.
